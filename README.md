🛒 Retail sales Data Analysis
📌 Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data to uncover sales trends, product performance, and customer purchasing patterns. The goal is to derive actionable business insights using Python-based data analysis techniques.

🎯 Objectives
Analyze overall sales performance
Identify top-performing products and categories
Examine monthly and regional sales trends
Generate data-driven business insights

🛠️ Tech Stack
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

📂 Dataset Features
Order ID
Product Name
Category
Quantity
Unit Price
Order Date
Customer Details
Region

🔎 Project Workflow
Data Cleaning
Handled missing values
Removed duplicates
Converted date columns to datetime format
Checked and corrected data types
Exploratory Data Analysis
Calculated total revenue and sales metrics
Performed category-wise and region-wise analysis
Identified top-selling products
Analyzed monthly sales trends
Data Visualization
Bar charts for product comparison
Line charts for trend analysis
Heatmaps for correlation analysis

📊 Key Insights
Identified peak sales months
Determined high revenue-generating products
Observed seasonal demand patterns
Highlighted areas for sales improvement
